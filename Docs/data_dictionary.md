# AtmoSync Data Dictionary

This document describes the columns in the AtmoSync Micro Climate Analytics dataset.

| Column                    | Description|
|
| Record_ID                 | Unique identifier for each observation|
| Date                      | Date on which the observation was recorded|
| Time                      | Time at which the observation was recorded|
| City                      | City where the observation was recorded |
| Latitude                  | Geographic latitude of the observation location |
| Longitude                 | Geographic longitude of the observation location |
| Temperature_C             | Ambient temperature measured in degrees Celsius |
| Feels_Like_C              | Apparent temperature or perceived temperature in degrees Celsius |
| Humidity_Percent          | Relative humidity expressed as a percentage |
| Dew_Point_C               | Dew point temperature measured in degrees Celsius |
| Pressure_hPa              | Atmospheric pressure measured in hectopascals |
| Rainfall_mm               | Amount of rainfall measured in millimeters |
| Wind_Speed_kmh            | Wind speed measured in kilometers per hour |
| Cloud_Cover_Percent       | Percentage of the sky covered by clouds |
| Solar_Radiation_Wm2       | Solar radiation measured in watts per square meter |
| PM2_5_ugm3                | Concentration of fine particulate matter (PM2.5) measured in micrograms per cubic meter |
| PM10_ugm3                 | Concentration of particulate matter (PM10) measured in micrograms per cubic meter |
| NO2_ugm3                  | Nitrogen dioxide concentration measured in micrograms per cubic meter |
| CO_mg_m3                  | Carbon monoxide concentration measured in milligrams per cubic meter |
| O3_ugm3                   | Ozone concentration measured in micrograms per cubic meter |
| AQI                       | Air Quality Index representing the overall level of air pollution |
| Population_Millions       | Population of the city expressed in millions |
| Energy_Demand_MW          | Energy demand measured in megawatts |
| Energy_Price_INR_kWh      | Energy price measured in Indian rupees per kilowatt-hour |
| Heat_Index_C              | Heat index representing the combined effect of temperature and humidity, measured in degrees Celsius |
| Pollution_Level           | Categorical classification of the pollution level |
| Climate_Opportunity_Score | Score representing the potential climate-related opportunity associated with the observation |
