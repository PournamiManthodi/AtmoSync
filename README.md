Dataset
12,000 records
27 variables

Project Overview

AtmoSync is a data analytics project focused on understanding how hyper-local climate conditions can create opportunities and risks within supply-chain decision-making.

The project combines climate data, analytical modeling, SQL, Python, and dashboarding to investigate environmental conditions and develop a data-driven framework for identifying potential market and spoilage opportunities.

Project Objectives

- Analyze climate and environmental conditions across Indian cities.
- Perform data cleaning and exploratory analysis.
- Identify relationships between climate variables and the Climate Opportunity Score.
- Build analytical datasets using SQL.
- Develop a simulated supply-chain layer for container and commodity analysis.
- Calculate spoilage-related metrics and potential arbitrage opportunities.
- Present findings through an interactive dashboard.
