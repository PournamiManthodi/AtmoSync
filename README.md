# AtmoSync
Micro-Climate Analytics using Python, Kafka, Snowflake, dbt and Apache Superset

Project Overview
AtmoSync is a micro-climate analytics project built using
Python, Apache Kafka, Snowflake, dbt and Apache Superset.

The project uses a 12,000-record environmental dataset
containing weather, air quality, energy and climate opportunity
information.

Dataset
12,000 records
27 variables
